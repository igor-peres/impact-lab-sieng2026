# Times

Cada time trabalha na sua própria pasta aqui dentro. Para criar a sua:

```bash
cp -r times/_MODELO_TIME times/time-03-nome-do-time
```

Use um nome claro: `time-<número>-<apelido>`. Dentro da pasta ficam o código, a
apresentação e o `README.md` de entrega (o modelo já vem pronto para preencher).

Não edite `_MODELO_TIME/` — ele é o molde para todos copiarem.
